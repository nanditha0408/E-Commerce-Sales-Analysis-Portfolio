# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Excel, MySQL, and Power BI to understand sales performance, profitability, customer segments, product categories, and order trends.

## Tools Used

- Excel
- MySQL
- Power BI

## Project Work

### Excel
- Cleaned and organized the raw sales data.
- Created PivotTables and charts.
- Analyzed sales, profit, orders, categories, customer segments, states, and payment methods.
- Created KPIs and key business insights.

### MySQL
- Imported and cleaned the sales dataset.
- Performed SQL-based sales and profit analysis.
- Analyzed categories, customer segments, states, payment methods, order status, products, customers, and discounts.
- Performed data-quality checks.

### Power BI
- Created an interactive sales dashboard.
- Added KPI cards for Sales, Profit, Orders, Quantity, and Profit Margin.
- Created monthly sales trends and performance charts.
- Added a date slicer for interactive filtering.

## Key Insights

- January recorded the highest monthly sales.
- June recorded the lowest monthly sales.
- Electronics generated the highest sales and profit among categories.
- Corporate had the highest sales and profit among customer segments.
- Karnataka recorded the highest sales among states.
- Debit Card recorded the highest sales among payment methods.
- Delivered orders were higher than Cancelled and Returned orders.

## Project Files

- `Excel` – Cleaned Excel workbook and analysis
- `SQL` – MySQL analysis script
- `Power BI` – Power BI dashboard
- `Screenshots` – Dashboard PDF

## Project Objective

The objective of this project is to demonstrate practical skills in data cleaning, SQL analysis, Excel analytics, data visualization, and business intelligence using Power BI.
